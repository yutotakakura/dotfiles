# Dotfiles

```sh
./install.sh             # brew bundle + シンボリックリンク作成
./install.sh --link-only # シンボリックリンクのみ
```

| リポジトリ | リンク先 |
| --- | --- |
| `ghostty/` | `~/.config/ghostty` |
| `nvim/` | `~/.config/nvim` |
| `starship/starship.toml` | `~/.config/starship.toml` |
| `zsh/.zshrc` | `~/.zshrc` |
